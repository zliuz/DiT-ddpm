## 先写清楚形状与下标

沿用 M2 的 0 基时间步：$t \in [0, T-1]$，其中 $t=0$ 是最后一次反向更新。反向循环执行 $T$ 次，最后一次更新产生最终图片。

$$
\begin{aligned}
x_T &\sim \mathcal{N}(0, I) && [B,1,28,28],\\
t=T-1 &: \quad x_T \to \text{网络} \to \hat{\epsilon} \to x_{T-2},\\
\cdots\\
t=1 &: \quad x_1 \to \text{网络} \to \hat{\epsilon} \to x_0
&& \text{（仍是带噪的第 0 级）},\\
t=0 &: \quad x_0 \to \text{网络} \to \hat{\epsilon} \to \text{最终图片}.
\end{aligned}
$$

注意：反向循环里的 $x_0$ 是「第 0 级带噪图片」，不是干净图片；干净图片是 $t=0$ 更新后的输出。文档中把后者写作最终图片或 $x_{-1}$，避免与训练时的干净 $x_0$ 混淆。

## 反向一步的推导

### 1. 从噪声预测反解干净图片

前向加噪关系是

$$
x_t = \sqrt{\bar{\alpha}_t}\,x_0
    + \sqrt{1 - \bar{\alpha}_t}\,\epsilon
$$

已知 $x_t$ 和网络给出的 $\hat{\epsilon}$，解出干净图片估计：

$$
\hat{x}_0 =
\frac{x_t - \sqrt{1-\bar{\alpha}_t}\,\hat{\epsilon}}
     {\sqrt{\bar{\alpha}_t}}.
$$

这就是 M5-1。**不裁剪** $\hat{x}_0$：$t$ 较大时 $\bar{\alpha}_t$ 很小，除以 $\sqrt{\bar{\alpha}_t}$ 会放大误差，这正是模型需要学习的地方；裁剪会改变训练时的均值公式，本阶段不引入。显示图片时才把像素裁到 $[0,1]$，采样张量本身保持原始值。

### 2. 后验均值

DDPM 的反向分布 $p(x_{t-1}\mid x_t)$ 近似为高斯，其均值由 $\hat{x}_0$ 与 $x_t$ 插值。记 $\bar{\alpha}_{\mathrm{prev}}=\bar{\alpha}_{t-1}$，并规定 $\bar{\alpha}_{-1}=1$：

$$
\mu =
\frac{\sqrt{\bar{\alpha}_{\mathrm{prev}}}\,\beta_t}
     {1-\bar{\alpha}_t}\,\hat{x}_0
+ \frac{\sqrt{\alpha_t}\left(1-\bar{\alpha}_{\mathrm{prev}}\right)}
     {1-\bar{\alpha}_t}\,x_t.
$$

这就是 M5-2。$t=0$ 时必须取 $\bar{\alpha}_{\mathrm{prev}}=1.0$，不能用 Python 负索引读 `alpha_bars[-1]`（那会读到 $\bar{\alpha}_{T-1}$，数值完全不同）。代入后 $t=0$ 的均值恰好等于 $\hat{x}_0$。

等价的简化写法是
$\mu = \left(x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}\hat{\epsilon}\right)/\sqrt{\alpha_t}$；两种写法在数学上相同。本练习要求用 $\hat{x}_0$ 的写法，便于对照「估计干净图片再后验插值」的思路。

### 3. 固定后验方差与最后一步

后验方差有两种常见选择：$\sigma_t^2=\beta_t$，或真实后验方差


$$
\tilde{\beta}_t =
\beta_t\frac{1-\bar{\alpha}_{t-1}}{1-\bar{\alpha}_t}
$$


本阶段选择 $\tilde{\beta}_t$。$t=0$ 时 $\bar{\alpha}_{-1}=1$，因此 $\tilde{\beta}_0=0$：最后一步自然不加噪声。$t>0$ 时

$$
x_{t-1} = \mu + \sqrt{\tilde{\beta}_t}\,z,
\qquad z \sim \mathcal{N}(0,I)
$$

这就是 M5-3。训练时的 $\epsilon$ 是「把 $x_0$ 加噪成 $x_t$ 时实际用的那份噪声」，是监督目标；采样时每一步的 $z$ 是新抽的随机噪声，不是网络预测的 $\hat{\epsilon}$，也不存在对应的训练目标。它让采样成为随机过程，同一张起点可以生成不同结果。

## 采样循环

M5-4 的要点：

- 初始噪声 `x_T` 用 `torch.randn(shape)` 在 **CPU** 生成，再 `.to(device)`；每步的 z 也在 CPU 生成后搬到计算设备。这样同一 CPU 种子在 CPU/MPS 上得到相同噪声序列，便于复现实验。
- `model.eval()` 并进入 `torch.no_grad()`；采样不需要梯度，也不更新参数。函数结束后模型保持 eval，训练循环会在 `train_step` 中切回 train。
- 循环顺序必须是 `T-1, T-2, ..., 0`，不能跳步；跳步需要配套的快速采样方法，本阶段不引入。
- 快照语义：`snapshots[t]` 是**执行第 t 步之前**的 x_t 的 CPU 副本。t=T-1 对应初始纯噪声，t=0 对应最后一次更新前的第 0 级带噪图片；最终结果单独返回。
- 函数内部不要 `manual_seed`。种子由调用方（测试或脚本）设置，避免训练中途采样打乱后续随机序列。

## 为什么训练一步，采样 T 步

训练时，对每张干净图片随机抽一个 t 和一份 ε，就能得到该步的带噪输入和监督目标。一次反向传播给出的是「在随机 (t, x_t) 上的期望梯度」，所以只需一步即可更新网络。

采样时没有干净图片和真实 ε 可用，只能从纯噪声开始，让网络在当前 x_t 上预测 ε，按公式走回更小的一级。每一步的输入都是上一步的输出，因此必须串行执行 T 次。训练目标相同、计算图完全不同，这是扩散模型最容易被混淆的地方。

## 完整训练与生成

`scripts/train_full.py` 遍历完整 MNIST，复用 M4 的 `make_training_batch`、`train_step` 和 checkpoint 格式；每 `--sample-every` 步保存一次 checkpoint 与固定种子样本。

先做短运行测量本机速度，再延长训练（耗时需实测，不根据设备型号推测）：

```bash

uv run python -m scripts.train_full --device mps --steps 100 \
  --batch-size 64 --sample-every 100 --output-dir outputs/m5/smoke

# 正式训练；按实测速度调整 steps 与 sample-every
uv run python -m scripts.train_full --device mps --steps 3000 \
  --batch-size 64 --learning-rate 1e-3 --sample-every 1000 \
  --output-dir outputs/m5/full
```

产物：

- `sample_step_XXXXXX.png`：训练过程中的固定种子样本，同一 seed 可纵向比较训练进度。
- `samples_final.png`、`trajectory_final.png`：训练结束后的样本与去噪过程。

周期采样会临时设置随机种子，脚本在采样前后保存并恢复 CPU RNG 状态，因此不会改变后续训练的随机抽样序列。

`--resume` 可继续更新模型、优化器和 step；数据顺序会从新一轮开始，不承诺与不中断训练的采样顺序逐位一致（M4 已验证的小样本恢复连续性不受影响）。
