## 先写清楚形状

默认配置为 S=28、P=4、C=1、D=128、depth=4、num_heads=4、mlp_ratio=4。

```text
x_t [B,1,28,28]
  → patchify             [B,49,16]
  → patch_projection     [B,49,128]
  + pos_embed            [1,49,128]  # 描述「这是哪个位置的 patch」
  + time condition       [B,1,128]   # 描述「这张图片处于哪个噪声时间步」
  → 4 Transformer blocks [B,49,128]
  → final_norm
  → output_projection    [B,49,16]
  → unpatchify           [B,1,28,28]
```

注意 16 是一个 patch 的原始像素数，128 是网络的隐藏维度。它们通过两端的线性投影连接，不能互相替代。

## 像素顺序与位置编码

token 先按 patch 网格的行、列排列。每块内部按像素行、像素列、通道排列。例如 4×4 的单通道编号图切成 2×2 块，第一个 token 应是 `[0,1,4,5]`，不是 `[0,1,2,3]`。

这种块内通道顺序是本练习明确选择的约定；多通道测试也检查该约定。往返相等还不够，因为两个方向可能犯相反错误，所以还提供独立手算像素测试。

位置编码使用可学习的 `nn.Parameter`，形状 `[1,N,D]`，在构造函数初始化一次，随后复用。图像大小在本阶段固定；更换边长需要重新构造对应网络。

## 时间编码与时间条件

固定时间编码的前半部分是 $\cos$、后半部分是 $\sin$。对 $j=0,\ldots,D/2-1$：

$$
\begin{aligned}
\mathrm{frequency}[j] &= \exp\left(-\log(\mathrm{max\_period}) \frac{j}{D/2}\right),\\
\mathrm{angle}[b,j] &= t[b] \cdot \mathrm{frequency}[j].
\end{aligned}
$$

原始 t 使用 M2 的 0–T−1 下标，不除以 T；`max_period=10000` 控制频率范围，并非最大允许时间步。固定编码之后再经过可学习的 `time_mlp`，增加 token 轴后广播到这张图片的所有 patch。

本阶段的条件方式是简单相加。原版 DiT 的 adaLN-Zero 留到 M7；当前不需要加入类别标签、CFG 或 VAE。

## 自注意力与残差

使用 `nn.MultiheadAttention`，自行组装 block 的前向路径，无需重写注意力内部的矩阵计算。

- `batch_first=True` 表示输入是 `[B,N,D]`，不能沿 B 轴混合不同图片。
- Q、K、V 均来自当前图片归一化后的 token，使用双向自注意力，不加因果 mask。
- 每条残差支路都保持 `[B,N,D]`；归一化在支路计算前执行。
- `dropout=0.0` 便于固定输入比较和初期调试。
- 模块赋给 `self`，block 堆叠使用 `nn.ModuleList`，位置向量使用 `nn.Parameter`。

按代码提示注册模块名称，其中 `output_projection` 是带 bias 的线性输出头。M3 保留普通线性层初始化，不强制将最终输出头置零，以便直接检查时间条件是否参与预测。

# M3-3：时间编码

uv run pytest -q
uv run python -m scripts.check_model --device cpu

检查脚本以合成图片调用 M2 加噪，再将 x_t 和 t 传入网络。它会保存参数量、形状、loss、梯度与更新结果到 `model_check.json`；一轮合成数据更新不代表模型已学会去噪。首次先用 CPU，成功后再验证本机 MPS。

`outputs/m3/` 不进入 Git。M2 可独立回归：`uv run pytest tests/test_diffusion.py -q`。
