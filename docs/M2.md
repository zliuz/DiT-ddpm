## 先明确时间步约定

本项目用 `x_0` 这个变量名表示干净图片，但**代码下标 t=0 已经代表第一次加噪**。

| 对象 | 代码下标 | 对应论文的扩散步 |
| --- | --- | --- |
| 干净图片 | 不占噪声日程的下标 | 0 |
| 第一次加噪 | 0 | 1 |
| 最后一次加噪 | T−1 | T |

因此 `alpha_bars[0]` 等于第一个 alpha，小于 1。不要在数组开头额外放入 1；绘图中的 `clean` 列会单独显示干净图片。

## TODO 1：构造噪声日程

beta 描述每一个局部加噪步骤的噪声方差。初始采用线性日程，T=1000，从 0.0001 增加到 0.02。

```text
alpha[t]     = 1 - beta[t]
alpha_bar[t] = alpha[0] × alpha[1] × ... × alpha[t]
```

alpha_bar 描述经历前面所有步骤后保留的累计信号比例。注意它是方差层面的系数；图片振幅的系数还要开平方。

手算检查：若 beta 为 `[0.1, 0.2, 0.3]`，alpha 应为 `[0.9, 0.8, 0.7]`，alpha_bar 应为 `[0.9, 0.72, 0.504]`。

查看 `torch.linspace` 与 `torch.cumprod` 的帮助，确认端点、计算维度、dtype 和 device。填写后运行：

```bash
uv run pytest tests/test_diffusion.py -q -k schedule
```

## TODO 2：提取系数与广播

训练 batch 中每张图片可以有不同时间步。若 `t=[2,0,2]`，你需要依次取出系数表中下标为 2、0、2 的值。

得到的 `[B]` 不能直接与 `[B,C,H,W]` 按图片相乘：PyTorch 广播从末尾维度对齐。应先变为 `[B,1,1,1]`，让每张图片的所有像素共享该图片自己的系数。

`extract` 接受 `x_shape`，请按输入维数构造单例维度，避免把所有像素的系数复制出来。

```bash
uv run pytest tests/test_diffusion.py -q -k extract
```

## TODO 3：每张图片独立采样时间步

时间步是离散整数。每次调用生成 `[B]` 个均匀分布的整数，最小值 0，最大值 T−1。查看 `torch.randint` 的上界约定。

随机种子由调用方设置，不要每次采样都重置种子。这里不需要图片、标签或神经网络。

```bash
uv run pytest tests/test_diffusion.py -q -k timesteps
```

## TODO 4：直接得到带噪图片

逐步加噪的局部形式与任意时间步的闭式形式有不同含义：

```text
局部一步：x_next = sqrt(alpha[t]) * x_previous + sqrt(beta[t]) * z

直接采样：x_t = sqrt(alpha_bar[t]) * x_0
             + sqrt(1 - alpha_bar[t]) * epsilon

其中 z 与 epsilon 均为标准正态噪声。
```

第二个公式已经包含前面所有步骤的累积影响，不需要循环执行 t 次。先生成或接收 epsilon，再用 `extract` 取系数并混合；当 batch 内时间步不同时，每张图片也必须使用正确的系数。

注意：

- 使用 `alpha_bar`，不是单步的 `alpha` 或 `beta`。
- 两个系数的**平方和为 1**；不是两个系数直接相加等于 1。
- `noise=None` 时自行生成标准正态噪声；给定 noise 时必须使用它，便于复查。
- 返回实际使用的 epsilon，它将在 M4 中作为模型的监督目标。
- 不修改 x_0 和传入 noise，不将 x_t 裁剪到 `[-1,1]`：正态噪声可以超出此范围。

```bash
uv run pytest tests/test_diffusion.py -q -k q_sample
```
